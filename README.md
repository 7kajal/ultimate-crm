# Ultimate CRM

Production-grade CRM built on **Next.js 16** (App Router, Turbopack, React Compiler) with **PostgreSQL + Drizzle ORM**, **Better Auth**, **shadcn/ui (base-nova / Base UI)**, **Vercel AI SDK**, **Razorpay**, **Meta WhatsApp Cloud API**, **Inngest**, **Pino** structured logging and **Sentry** error tracking.
